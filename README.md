Este é um projeto simples criado como parte de um exercício sobre CSS.

Objetivo:
O objetivo foi criar uma página HTML com estrutura semântica (`<header>`, `<section>`, `<aside>`, `<footer>`) e estilizá-la com CSS, aplicando uma paleta de cores harmoniosa gerada para a atividade.

Tecnologias Utilizadas:
HTML
CSS

Paleta de Cores:
Fundo: `#F4F7F5` 
Texto: `#2D3436` 
Primária: `#0A3D62` 
Secundária: `#1E8BC3` 
Destaque: `#F39C12`
